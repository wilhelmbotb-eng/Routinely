# Routinely

A luxury black-and-white Android routine and productivity app built with Kotlin and Jetpack Compose.

## Routinely 2.0 direction
Offline-first daily planning with an optional secure AI assistant.

## Available in the current build
- Premium monochrome dashboard
- Add routines and mark them complete
- Local on-device routine persistence
- Daily progress overview
- Completion streak foundation
- Starter achievement badges
- AI assistant screen with example prompts (secure AI backend not connected yet)

## Build an APK
1. Open the **Actions** tab.
2. Select **Build Routinely APK**.
3. Tap **Run workflow**.
4. Open the completed workflow run.
5. Download the **Routinely-debug-apk** artifact and extract the ZIP.

## Important
Smart alarms, home-screen widgets, calendar integration, cloud sync and real AI responses are not available yet. AI provider credentials must stay on a secure backend and must never be embedded in the Android APK.
