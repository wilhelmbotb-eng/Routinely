# Routinely

A black-and-white Android routine planner built with Kotlin and Jetpack Compose.

## Current build
- Daily dashboard with progress indicator
- Add routines
- Mark routines complete
- Today, Stats, Alarms and Settings navigation
- GitHub Actions workflow to build a debug APK

## Build an APK
1. Open the **Actions** tab in this repository.
2. Select **Build Routinely APK**.
3. Tap **Run workflow**.
4. Open the completed workflow run.
5. Download the **Routinely-debug-apk** artifact.

The APK is a debug build for testing. Smart alarm scheduling, persistent storage, home-screen widgets, habit streaks and custom sounds are planned for later milestones.
