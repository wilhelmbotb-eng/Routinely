# Routinely

A luxury black-and-white Android routine and productivity app built with Kotlin and Jetpack Compose.

## Routinely 2.0 direction
Offline-first daily planning with an optional secure AI assistant.

## Available in the current build
- Premium monochrome dashboard with personal greeting
- Add, edit, delete and complete routines, saved on the device
- Real daily reminders with snooze, restored after reboot
- Stats: streaks, weekly chart, monthly totals, achievements
- Settings: name, reminders, snooze length, backup and restore
- AI tab: offline routine planner, plus a connection to your own secure AI backend (see `docs/ai-backend/worker.js`)

## Build an APK
1. Open the **Actions** tab.
2. Select **Build Routinely APK**.
3. Tap **Run workflow**.
4. Open the completed workflow run.
5. Download the **Routinely-debug-apk** artifact and extract the ZIP.

## Important
Home-screen widgets, calendar integration, weekday-specific schedules and cloud sync are not available yet. AI provider credentials must stay on a secure backend and must never be embedded in the Android APK.
